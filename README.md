# Revit Floor Plan Tools · 床伏図ツール

在 Revit 里打开「床伏図ツール → 自動寸法」。面板可停靠在右侧，可对当前平面视图整体生成尺寸，也可框选局部生成。框选采用与构件范围相交的方式。两种模式共用面板所选的一个 Revit 线性尺寸类型。

## 安装和首次试用

1. 解压安装包，双击 `Install.cmd`。安装到当前 Windows 用户的 Revit 2024 加载项目录。Revit 已在运行时，新版在下次启动时加载。
2. 启动 Revit 2024，打开带轴线和可见结构链接的空白床伏図。建议先框选一根柱、一段梁或一端墙，核对见证线取点，再运行整图。
3. 运行时，进度条显示扫描、计算和尺寸链的处理进度。生成后查看「要確認」。选择铁骨候选行，点击「選択した部材を表示」可定位，确认对象后点「選択した鉄骨に寸法を作成」可单独补标其尺寸。用 Revit 的一次撤销回退本次创建的尺寸和移动的梁符号。

升级可再次运行安装脚本，保留本机的族映射。卸载时退出 Revit，运行 `Install-Addin.ps1 -Uninstall`。

## 链接构件的三维选择框

点「床伏図ツール → リンク選択ボックス」，在图上点选 RVT 链接里的一个或多个构件，再点「完了」。也可先用 Tab 选中链接构件再点按钮。插件将构件范围转换到宿主坐标，在「無題」三维视图中用 300 mm 余量显示。旧版专用视图在再次使用时自动改名。可用 Revit 的 `KS` 为「リンク選択ボックス」分配快捷键。

## 柱、梁符号

打开「柱・梁タグ」页签，在「柱タグタイプ」「梁タグタイプ」里分别选择宿主项目已加载的标记族和类型。选「記入しない」可以跳过一类，只标柱或只标梁。若无可选类型，在 Revit 加载相应的标记族后，重新点功能区的「自動寸法」刷新。选择整图或框选范围，再点「柱・梁タグを作成」。

插件为当前视图内兼容的本项目与 RVT 链接构件创建原生关联标签。确认属于同一根 SRC 柱的外部混凝土与内钢件统一标在柱主体上，嵌套子柱与同源同位置的重复链接也并入同一个柱符号。在同一视图重复运行时跳过已有的柱、梁标签。柱标签放在当前视图中柱外包框的左下角内侧，默认留 0.5 mm 的纸面边距；遇重叠时就在左下角附近让位。梁标签优先放在跨中附近。没有空位或无法标记的构件列入「要確認」。使用 Revit 一次撤销可回退本批创建的标签。

## 尺寸规则

- **取数来源**　轴线统一取当前项目。构件从当前视图可见的链接实例收集，采用链接实例的变换处理位置。
- **轴距**　整图模式可同时标主轴网跨距。相对两侧各有各的尺寸链。
- **RC / SRC 柱**　混凝土和内钢柱各出独立尺寸链。混凝土用外轮廓定位，有加厚时另标「加厚 → 本体 → 加厚」。柱本体与嵌套加厚族各取实际侧面引用，零加厚侧沿用本体边。外轴定位并入混凝土外侧链，一侧足够。内钢柱在两个方向各标轴线定位与钢柱总宽。分别建模的构件在共同标高核验包覆。多个候选通过时，优先比较族从属关系、当前视图切平面和截面中心偏差，双方均唯一时配对。同源且同位置的重复链接只处理一次。仍有冲突时可通过「要確認」定位具体元素。独立 S 柱跳过。
- **柱尺寸查重**　按当前视图已有尺寸的引用构件、方向和见证点逐段核对，保留手动和此前自动生成的尺寸。混凝土、加厚和内钢柱分别检查，只补缺少的尺寸。
- **梁**　用轴线定位到梁本体中心。梁正中放横向定位尺寸，已有梁符号发生碰撞时优先沿梁移位。有加厚时分列本体和加厚。倾斜梁留待复核。
- **梁幅の表記**　默认「全幅」，也可选「梁芯で分割」或「梁幅を記入しない」。当板端至梁近边为 750 mm、梁宽为 300 mm 且梁芯居中时，对应尺寸链为 `750 + 300`、`750 + 150 + 150` 或 `750`。此选项适用于本次生成。
- **梁芯连续定位**　同向平行梁有公共跨度时，在共同的横截面处把外侧基准轴线与各梁芯串成一道尺寸链。连链成功后，跳过这组梁本次重复的单独梁芯定位。
- **板下梁与钢梁**　从可见链接补查与可见楼板同层或接触板底的水平直梁。梁的参照可来自实体侧面、纵向边或族参照。裸钢梁按截面外边及梁芯取点。
- **墙**　以墙边和轴线取点。穿轴时标两侧距离，有加厚再标厚度组成。加厚变化处沿墙定位，从一条轴线接连续链。自由端与变化点相距不超过 5000 mm 时可并链。自由端单独标时，若两侧有定位轴线则都接入。斜墙两端各找最近横轴，并选该端靠横轴的墙角，两方向定位。
- **板边与开口**　已由柱、梁、墙尺寸覆盖的板边共用。独立板边凹口的两侧拐角同链定位。普通板端夹在两条轴线中时标两段定位，并共用已有的轴间总尺寸。板侧同跨内有平行梁时可加板端到梁近边的尺寸。矩形检修口按中心定位。电梯井对有明确引用的板边取最近轴线、梁边和梁轴线。开口净尺寸暂缓。
- **排布**　面板可调柱两端首排离外边的距离（默认 250 mm）和两排柱尺寸线之间的间距（默认 360 mm）。其余构件首排默认 600 mm。柱总宽数字优先居中，放得下且没有文字重叠时，即使下方有梁线也可居中。新生成的数字与文字、标签或其他尺寸值重叠时沿原尺寸线平移。全部尺寸生成后复查，后创建的数字遇到遮挡时，也会尝试平移与它碰撞的先创建数字。搜索空位时同时避开可见的梁、柱、墙。附近没有空位时列入「要確認」。梁中点的尺寸线与梁符号重叠时，可按面板选项沿梁移动符号。

## 族映射与验证范围

插件创建关联模型引用的原生尺寸，并在提交前核对分段长度。族几何和参数需能区分本体、加厚及内钢柱。族参数名称和开口分类词可在安装目录内的 `FamilyMap.xml` 调整。若缺少有效引用、类别用途不明，或 Revit 拒绝该链，面板会列出具体原因。复杂裁剪、非矩形族和旋转链接建议在空白视图分批核对。

## 从源码构建

需要 Windows、Revit 2024、.NET SDK 和 .NET Framework 4.8 Developer Pack。Revit API 程序集取自本机安装。安装位置与默认值不同时，构建命令需指定 `-p:RevitInstallDir="实际路径"`。

```powershell
dotnet build -c Release
.\Install-Addin.ps1
```
